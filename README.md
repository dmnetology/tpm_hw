# Цикл домашних заданий по курсу «Теория и практика многопоточности»

Spring Boot, встроенная база H2.

Каждое домашнее задание находится в соответствующей ветке, отчет по заданию — в README соответствующей ветки:

- `task1` — Домашнее задание 1. Создание и запуск потоков через Thread и Runnable
- `task2` — Домашнее задание 2. Жизненный цикл потока
- `task3` — Домашнее задание 3. Параллелизм и параллельность
- `task4` — Домашнее задание 4. Синхронизация потоков
- `task5` — Домашнее задание 5. Блокировка доступа к ресурсам. ReentrantLock и Condition

## Запуск

Открыть проект в IntelliJ IDEA (JDK 21) и запустить `DemoApplication`. При старте выполняется демонстрация задания той ветки, на которой вы находитесь.
