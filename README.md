# Отчёт по Домашнему заданию 1. Основы потоков

Каркас проекта на Spring Boot по итоговому заданию готов и проверен - приложение запускается.

## Ход работы

1. **Классы задач.** `CounterWorker implements Runnable` и `LoggerThread extends Thread` — задача описана двумя способами; оба потока выводят на экран имя потока и порядковый номер (1…5), между выводами пауза 100 мс.
2. **Имена потоков.** `CounterWorker` — вторым аргументом конструктора `new Thread(runnable, name)`; `LoggerThread` — в конструкторе через `super("LoggerThread")`.
3. **Класс сервиса.** `ThreadDemoService` — создаёт оба потока, запускает их (`start()`), выводит список всех активных потоков (`Thread.getAllStackTraces().keySet()`) и ожидает завершения (`join()`).
4. **Запуск демонстрации.** Выполняется автоматически при старте приложения (`CommandLineRunner` в `DemoApplication`).

## Результат (фрагмент консоли)

```text
LoggerThread: порядковый номер 1
CounterWorker: порядковый номер 1
=== Список всех активных потоков (всего 27) ===
  6. CounterWorker
  10. LoggerThread
  ...
=== Оба потока завершили работу ===
```

Номера чередуются — потоки работают конкурентно; наша пара видна в списке активных потоков среди системных потоков JVM и Tomcat.

## Запуск

Открыть проект в IntelliJ IDEA (JDK 21) и запустить `DemoApplication`.
